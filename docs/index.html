Placeholder guild tools

Two small pieces connect the game to the guild's Discord and officer sheet: an addon everyone can run, and a tray app one officer runs.

Everyone in the guild: the addonPlaceholderSync records the guild bank whenever you open it, so the guild sees stock and history in Discord and on the sheet, and keeps your characters in the roster. Nothing to set up: install it and play.
The bridge: officers, and raiders who want to helpPlaceholder Bridge sits in the tray, uploads the bank scan and the bank's own log whenever you visit the bank. One officer is enough; every extra linked PC keeps the bank more current.

The addon

  1. Easiest: install PlaceholderSync from CurseForge with the CurseForge app, which also keeps it updated. Or download the addon zip from Downloads above; its name is PlaceholderSync-<version>.zip.
  2. With the zip: unzip it into the AddOns folder of your WoW Forever install, so that Interface\AddOns\PlaceholderSync\PlaceholderSync.toc exists.
    Typical location: C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\. For testing on retail, the same under _retail_.
  3. Start the game, or type /reload if it is running. In chat, /psync shows the addon's status. The addon says nothing in chat by itself; /psync chat on turns on a line when a bank scan is saved, /psync prompt on offers a Reload button after each bank visit so the scan reaches the bridge straight away, and /psync help lists the other settings. /psync also tells you whether your last scan reached the server.

That is all a raider needs. From then on every guild bank visit is recorded, and your characters are known to the roster.

The bridge

Officers link as officers. Raiders with a rank role can link too: their bank visits upload like an officer's.

  1. Download the installer from Downloads above and run it. The app starts in the system tray and opens its window.
  2. Open Guilds and press Link this PC. Your browser opens a page on the guild server: sign in with Discord, tick the guilds this PC should serve, Approve. The app picks the result up by itself within a few seconds.
    Officers, administrators and the server owner link as officers; Raider, Trial and Social roles link as members. Nothing to paste.
  3. In the game, open the guild bank, click through its tabs, close it and type /reload.
  4. Back in the bridge, Game accounts lists your account once the addon has written its file, and the Overview shows the scan uploading. In Discord, /gbank stock shows the bank, and the sheet's Guild Bank tab fills in within seconds.

From then on it is automatic: every bank visit followed by a /reload or logout uploads the scan and the bank's own transaction log. The bridge updates itself; by default it installs updates only while the game is closed.

Windows Defender may warn about the installer. The installer is not yet code-signed, and Defender's heuristics sometimes flag small unsigned installers as Trojan:Win32/…!ml. To check a file is the real one, compare its SHA-256 with the hash shown under Downloads above, using PowerShell: Get-FileHash .\Placeholder.Bridge_x.y.z_x64-setup.exe. Then choose Allow in Windows Security › Protection history.

Two guilds on one PC

Tick both guilds when you link. Each WoW install is matched to the guild named in its addon file, so _forever_ and _retail_ can serve different guilds; Game accounts lets you pin an install to a guild if the match is not what you want. Unlinking a PC is done in the guild's Discord with /settings devices.

Setting up a new guild

Once per guild, by a Discord server administrator. Everything else on this page assumes it is done.

  1. Add the bot to the guild's Discord server (you need Manage Server there). Then, as a server administrator, run /setup start guild_name:<in-game guild name> in that server. The reply, visible only to you, holds the sheet webhook secret needed in step 3.
  2. Make a copy of the officer sheet template. Google asks you to copy it; name the copy after the guild. The template itself is view-only, the copy is yours with every tab, formula and menu.
    Whoever makes the copy owns it, so use the Google account of the officer who will keep the sheet.
  3. Open the copy; the menus (Guild, Rosters, Splits, Loot, Settings) appear a few seconds after the first load. Run Settings menu → Set up this copy (new guild, run once)…. Google asks for permission the first time: allow it, and run the item again if the dialog did not continue. It shares the sheet with the bot, saves the webhook secret, installs the timed jobs and ends with the exact /settings sheet line to paste in Discord.
  4. In Discord, /settings onboard walks through the remaining settings (officer roles, wishlist forum, bank channels, log channels, rank roles) with Discord's own pickers.

Only your own guild's data is recorded. The addon refuses another guild's bank, and the server refuses anything from a guild other than the one the token belongs to. Nothing is read from chat, your friends list or your Battle.net account.

If something does not look right

  • "this is X's bank, not Y's: not recording it" in chat: you are in a different guild than the one the bridge serves. Expected on alts elsewhere.
  • Bridge says "Server rejected the token": this PC was unlinked or the token was rotated. Guilds › Link this PC again.
  • "No guild to link" on the approval page: you hold no officer or rank role in a Discord server that uses the bot. Ask an officer for your rank role, then link again.
  • No scan arrives: open the bank, click each tab, close it, and /reload. The file is only written when the game saves it.
  • Something missing in game: /psync apicheck lists any API the client lacks; send that output to the bot owner.
